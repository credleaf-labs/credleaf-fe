# credleaf-fe

Issuer console and public verification UI for CredLeaf.

## Stack

- React latest + React Compiler
- TypeScript
- Next.js App Router
- ky API client
- GitHub Actions CI

## Features

- Credential template list and creation flow.
- Credential issuance and revocation screens.
- Public credential verification page.
- Audit log view with cursor-based pagination.
- Shared ky client for API requests and error handling.
